# 饿了么 Motion 光轨创意页

一个以“生活随叫随到”为主题的原创品牌概念长页面，使用 Motion、Lenis 与原生 Canvas 构建。

[在线体验](https://tfiyw-wei.github.io/eleme-motion-landing-page/)

## 特点

- 城市夜景与配送光轨首屏
- Motion 驱动的章节入场和路径动画
- Lenis 平滑滚动
- 原生 Canvas 粒子网络
- 桌面、平板和手机响应式适配
- `prefers-reduced-motion` 与低性能设备降级
- 单文件页面，可直接打开 `index.html`

## 本地运行

直接双击 `index.html`，或使用任意静态服务器打开。Motion 和 Lenis 通过 CDN 加载；网络不可用时会使用浏览器原生动画后备。

## 声明

本项目是饿了么主题创意概念展示，并非饿了么官方页面。页面不提供真实下单、支付、下载或用户信息收集功能。页面中的演示数据和用户评价均为概念文案。
