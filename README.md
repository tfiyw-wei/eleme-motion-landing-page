# 饿了么 · 这一口，就是现在

由 **AI 产品经理**创作的饿了么品牌体验概念作品，围绕美食发现、点餐决策与配送理解展开。

## 这一版

- 以明亮饿了么蓝、热饭、外卖餐袋与饮品建立品牌识别；主视觉与餐品场景由 ImageGen 生成。
- 用五段叙事串起美食发现、点餐助手、一天四个场景、配送演示与创作者理念。
- 点餐原型按示例餐品价格、用餐场景、不吃辣与素食筛选，并展示匹配原因；用户可随时改变条件。
- 场景切换可将需求带入点餐助手；推荐餐品可进入配送演示，不产生真实订单。
- 配送提供四个手动阶段和播放/暂停/重播，支持后台暂停。
- 保留六个服务详情、场景指南和配送说明，支持直接链接与浏览器前进/后退。
- 无第三方前端依赖、外部字体、追踪、真实地址收集或支付接口；手机布局、键盘操作与减少动画偏好得到支持。

## 本地运行

```sh
python3 -m http.server 8765
```

访问 `http://localhost:8765/`。也可以直接打开 `index.html`；所有核心静态资源均为本地文件。

## 文件结构

```text
index.html          页面内容与语义结构
assets/style.css    视觉系统与响应式布局
assets/app.js       推荐规则、场景、配送、哈希路由
assets/*.jpg        生成的品牌与餐品图片
yumu/index.html     原有 YUMU 页面，保留
DESIGN-NOTES.md     改版依据、能力边界与后续验证方向
IMAGE-PROMPTS.md    图像来源与最终生成提示词
```

## 能力边界

这是非官方品牌概念作品。点餐助手目前是**基于本地示例菜单的规则原型**，没有接入真实 AI 模型、商家数据库、用户画像或配送系统。餐品、价格、图片、地图与订单状态为示例，不提供真实交易。推荐筛选中的价格仅为餐品示例价，不包含真实配送与包装费用。图片用于类别示意，不代表真实商品。

2026-10-12 参考官网时，`https://www.ele.me/` 已跳转至淘宝闪购官网；本作品按创作主题保留饿了么蓝色品牌表达，不宣称是当前官网复刻。
