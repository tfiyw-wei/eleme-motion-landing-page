# 饿了么 · 城市脉冲创意页

一个以“生活随叫随到”为主题的原创品牌概念长页面，使用 Motion、Lenis 与原生 Canvas 构建。

[在线体验](https://tfiyw-wei.github.io/eleme-motion-landing-page/)

## 特点

- 城市夜景首屏，双层倾斜轨道与流动光束
- 点击“点亮城市”触发可重播的扩散脉冲
- 美食、咖啡、鲜花三组悬浮动态图，搭配环绕光轨与投影底座
- 支持手动暂停动态图、离屏暂停及后台暂停
- Motion 章节入场与配送路径动画，网络不可用时使用浏览器原生动画后备
- Lenis 桌面平滑滚动，手机保留原生滚动
- 原生 Canvas 粒子网络，按设备减少粒子和渲染分辨率
- 桌面、平板和手机响应式适配，遵循 `prefers-reduced-motion`
- 单文件页面，内嵌主视觉复用，约 733 KiB

## 本地运行

直接双击 `index.html`，或使用任意静态服务器打开。Motion 和 Lenis 通过 CDN 异步加载；页面内容、图片、CSS 动效与原生动画后备可离线使用。

## 声明

本项目是饿了么主题创意概念展示，并非饿了么官方页面。页面不提供真实下单、支付、下载或用户信息收集功能。页面中的演示数据和用户评价均为概念文案。
